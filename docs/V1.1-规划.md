# MeWork · V1.1 规划（多文件格式支持 + Markdown 内嵌 HTML）

> 版本：v1.0（2026-08-12 规划）
> 排期来源：《进度看板》待办区（2026-08-12 用户定案，源自 `WorkRegion/MeWork功能优化文档1-发现问题.md`）
> 定位：V1.1 为 v1.1.0-optimize 之后的下一里程碑；本文档承接两个功能项的规划，开发前仍须细化定稿并登记《进度看板》子阶段。
> 配套：《需求规格文档》·《开发计划》§四（后续迭代）·《docs/当前实现-架构设计.md》

## 1. 目标

在现有「工作区 + 文件编辑」核心上扩展，使 MeWork 不止编辑 Markdown：

1. **多文件格式可插拔支持**：可编辑 / 预览 yaml、json、js、ts、java、python 等常见代码与数据格式，并支持自定义后缀（如 `.LfcDoc`）；目录树、编辑器高亮、预览渲染统一以「格式注册表」为准。
2. **Markdown 内嵌 HTML 渲染增强**：MD 中原始 HTML 不再一律转义，按 HTML 渲染；` ```html ` 围栏代码块也按 HTML 渲染预览——全部经 DOMPurify 白名单兜底。

## 2. 范围界定

### 2.1 多文件格式可插拔支持

- **内置格式**（代码注册，开箱即用）：markdown（md）/ 纯文本（txt、无后缀）/ 常见代码与数据格式（yaml、yml、json、js、mjs、cjs、ts、java、py 等，范围开发前拍板）
- **自定义后缀**：设置页「支持文件格式」管理界面，可新增自定义后缀（如 `.LfcDoc`）并指定其类别（代码 / 数据 / 文本）
- **双形态**：写代码注册 + 图形化配置，二者并存（用户定案「两者都要」）
- **三处统一查注册表**：目录树过滤 / 编辑器高亮 / 预览渲染
- 超出当前行为：目录树范围现为「无后缀 / md / txt」（9.2.8 定案），注册表落地后以此为准扩展

### 2.2 Markdown 内嵌 HTML 渲染增强

- `markdown-it` 的 `html: false` 改为 `html: true`（原始 HTML 按 HTML 渲染）
- ` ```html ` 围栏：自定义 fence 规则，info 为 `html` 时按 HTML 渲染（当前为转义代码块）
- 安全兜底：DOMPurify 全量清理（沿用强化版 `ALLOWED_URI_REGEXP`，阻止 `javascript:` / `vbscript:` / `file:` 等注入）

## 3. 架构方案

### 3.1 格式注册表（`src/shared/format-registry.js`，主/渲染共用）

单一来源，与 `link-policy.js` 同模式（避免双份漂移）：

```js
{
  ext: '.md',            // 后缀（含点）；无后缀用特殊 key
  name: 'Markdown',
  category: 'markdown',  // markdown | code | data | text
  language: 'markdown',  // CodeMirror 语言扩展映射
  preview: 'markdown'    // markdown | code | text（预览渲染方式）
}
```

- **内置表**：代码注册默认格式集合
- **自定义表**：设置页写入（localStorage 持久化），追加 / 覆盖内置
- 查询 API：`getFormat(relPath)` / `isSupported(relPath)` / `listEnabled()`

### 3.2 三处接入

| 接入点 | 现状 | 改动 |
|---|---|---|
| 目录树过滤 | `FileTree` 硬编码「无后缀 / md / txt」 | 过滤逻辑改查注册表 |
| 编辑器高亮 | `CodeMirrorEditor` 固定 `lang-markdown` | 按当前文件 ext 查注册表，动态装配 CodeMirror 语言扩展（代码格式需引入 `@codemirror/lang-*` 对应包） |
| 预览渲染 | `renderMarkdown` 固定 markdown-it | 按注册表：`markdown` 类别走 markdown-it；`code` / `data` 类别走语法高亮只读视图；`text` 类别走纯文本 |

> 依赖变化：`code` / `data` 格式的高亮需新增 CodeMirror 语言包（`@codemirror/lang-json`、`lang-yaml`、`lang-javascript`、`lang-python`、`lang-java` 等，按定稿格式范围引入，均与现有 `codemirror` 包同族）。

### 3.3 HTML 渲染（改动集中在 `src/renderer/src/utils/markdown.js`）

- `new MarkdownIt({ html: true, ... })`
- 新增 fence 规则：`info === 'html'` 时输出原始内容交由 DOMPurify 清理（而非转义代码块）；其余 info（含空）维持现状
- DOMPurify 兜底不变；预览图片 `mework-file://` 处理不变（HTML 内的相对图片同样经 `ALLOWED_URI_REGEXP` 白名单）

## 4. 影响面与风险

| 项 | 说明 |
|---|---|
| 目录树行为 | 支持格式范围变化，`.wr/` 仍隐藏（图片资产不进树）；自定义后缀可能影响右键「新建 MD 文件」入口（新建格式列表随注册表扩展） |
| 编辑器 | CodeMirror 语言包按需动态加载；切换文件时语言扩展随之切换，需保留光标与撤销栈 |
| 预览安全 | `html:true` 是 XSS 面扩大，唯一防线为 DOMPurify——需回归测试强化白名单（含 `mework-file:`、`data:` 图片），评审必过 |
| 性能 | 预览渲染现为全量渲染，代码类大文件预览按注册表渲染时考虑防抖（承接 9.3.6 候选优化：按内容尺寸防抖） |
| 版本历史 | 代码 / 数据格式文件同样记版、可对比 / 回滚（版本系统与格式无关，天然兼容） |

## 5. 验收标准

- **格式注册表**：内置格式开箱即用；新增自定义后缀（如图形化添加 `.LfcDoc`）立即在目录树可见、可打开编辑、可预览
- **三处统一**：目录树过滤、编辑器高亮、预览渲染均以注册表为准，无硬编码格式清单残留
- **HTML 渲染**：MD 中原始 HTML 与 ` ```html ` 围栏按 HTML 渲染；`javascript:` 等危险协议 / 事件属性被 DOMPurify 拦截；本地 `mework-file://` 图片不受影响
- **回归**：现有 md / txt 行为不回归（自动保存、记版、外部改动检测、同步滚动）；lint / 单测 / 构建通过
