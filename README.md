# MeWork

结合编辑与版本管理的**本地工作记录桌面应用**（Electron + React + JavaScript）。

《WorkRecord》的极简重构——砍掉 AI 与日程，保留最核心的**设定工作区 + 编辑文件**，聚焦轻量、纯粹与可追溯。**未来预留 AI 扩展**（架构预留，见《需求规格文档》§7）。

> 当前状态：**v1.0.0 MVP** ✅（阶段 0–8 全部完成，2026-08-11）

## 安装

- **Windows**：运行 `MeWork Setup 1.0.0.exe`（NSIS 安装包），可选安装目录与桌面快捷方式。
- 安装完成后从桌面 / 开始菜单启动 **MeWork**。

## 使用说明

### 首次启动：选择工作区

- 首次运行会进入引导界面，**选择一个本地文件夹作为工作区**（你的真实文件夹，只放你自己的文件）。
- 工作区路径会记忆，重启后自动恢复；侧边栏顶部可随时**切换 / 更换**工作区（含最近使用列表，可移除记录，不删除磁盘文件）。

### 侧边栏：工作区与目录树

- 顶部为当前工作区（路径 + 切换菜单）。
- 文件夹图标一键**展开 / 收回**文件列表；文件夹懒加载子级，点击整行展开 / 关闭。
- **右键**目录节点进行文件管理（目录树 CRUD 唯一入口）：
  - 文件夹右键：新建 MD 文件 / 新建文件夹 / 重命名 / 删除 / 刷新
  - 文件右键：版本历史 / 重命名 / 删除
  - 顶部文件夹图标右键：新建（根目录）、刷新
- 删除有二次确认，非空文件夹额外警告；删除时版本历史一并清空。
- 侧边栏右缘可**拖拽调宽**，宽度自动记忆。

### 编辑器

- 点击文件在**标签页**中打开，支持多文档并行编辑；关闭未保存标签会提示 保存 / 放弃 / 取消。
- 默认**「编辑 | 预览」分屏**并排；工具栏切换 分屏 / 仅编辑 / 仅预览；拖拽分隔条调比例。
- **自动保存**：停止编辑约 **30 秒**后触发（防抖，持续输入不触发）；也可手动保存（按钮或 `Ctrl+S`）。工具栏显示 已保存 / 保存中 / 未保存。
- 预览支持标准 Markdown 语法，相对路径图片基于文件所在目录解析，远程 `https://` 图片直接显示；外链（http/https/mailto/tel）用系统浏览器打开。
- **专注模式**（`F11`）：隐藏侧边栏与顶栏，最大化编辑空间；`Esc` 或悬停边缘临时唤出。

### 版本历史

- 每次保存自动生成版本快照（内容无变化不记版），存于工作区 `.wr/versions/`。
- 文件右键 → **版本历史**，右侧滑出面板；可查看各版本时间与来源。
- **对比**：单选对当前、双选对任意两版，主区行级 diff。
- **回滚**：可回到任意历史版本（产生新版本，不覆盖历史）。
- **导出**：将某版本另存为独立文件（默认落工作区外）。
- 保留策略：最近 10 版全量 + 更早每 10 版留 1 里程碑 + 超过 50 版自动精简，编号不重排。

### 主题与设置

- 顶栏**眼睛图标**三态循环：浅色（睁眼）/ 深色（闭眼）/ 跟随系统（半睁+指示点）；手动选择后不再自动跟随。
- 顶栏**齿轮**打开设置：外观（主题 / 字体三选 Inter · 系统 · 等宽）/ 编辑器（自动保存开关、防抖间隔、字号）/ 工作区（路径、更换）/ AI（预留，灰显）/ 关于。

## 快捷键

| 按键 | 功能 |
|---|---|
| `Ctrl+S` | 手动保存当前文件 |
| `F11` | 专注模式开 / 关（工作区激活时） |
| `Esc` | 退出专注模式 / 关闭弹窗、菜单 |

## 数据与文件

- **真实落盘**：MD/TXT 文件直接读写你选择的文件夹，可用其他编辑器直接打开；应用内改动即时生效，外部改动经「刷新」感知。
- **目录整洁**：所有软件衍生数据集中存放在工作区隐藏目录 `.wr/`，不污染用户文件夹——
  - `.wr/versions/<文档相对路径>/`：版本库（`V{n}.md` 快照 + `meta.json`）
  - `.wr/logs/`：错误日志
- 全部文件读写经**路径沙箱**（pathGuard），限定在工作区根目录内。

## 技术栈

- 桌面框架：**Electron**（主进程 Node + 渲染进程 React）
- 语言：**JavaScript**；构建工具 **electron-vite**
- 编辑器：**CodeMirror 6**；预览：**markdown-it + DOMPurify**；安全基线 `contextIsolation` / `nodeIntegration:false` / `sandbox:true`
- AI：当前版本不含；模块目录与 IPC 前缀已预留扩展点（PRD §7）

## 开发

```
npm install     # 安装依赖
npm run dev     # 开发模式
npm run build   # 构建（out/）
npm run lint    # ESLint
npm run format  # Prettier
npm test        # 单测（node --test）
npm run dist    # 构建 + Windows NSIS 打包（release/）
```

各阶段里程碑对应 git 标签（`v0.0.1-workflow` … `v1.0.0-mvp`），详见《进度看板.md》。
