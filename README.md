# MeWork

结合编辑与版本管理的**本地工作记录桌面应用**（Electron + React + JavaScript）。

《WorkRecord》的极简重构——砍掉 AI 与日程，保留最核心的**设定工作区 + 编辑文件**，聚焦轻量、纯粹与可追溯。**未来预留 AI 扩展**（架构预留，见《需求规格文档》§7）。

> 当前阶段：阶段 0 · 项目基础设施（git + 文档体系 + 工作流配置）进行中。

## 核心特性

- **工作区**：设定 / 多工作区 / 最近工作区列表，真实文件夹直读直写
- **MD 编辑器**：三态（默认分屏「编辑 | 预览」、比例可调、可隐藏）、自动保存（1s 防抖）、`Ctrl+S`、专注模式
- **目录树与文件管理**：新建 / 重命名 / 删除（二次确认）
- **MD 预览**：标准语法渲染、相对与远程图片、外链系统打开
- **版本历史**：`.wr/versions/` 集中快照、确定性保留策略、行级 diff、回滚、导出
- **标签页**：多文档并开，状态持久化
- **明暗主题**：仿 Apple 风格、浅色 / 深色、跟随系统、字体切换（含汉字）
- **目录整洁**：所有衍生数据集中 `.wr/`，用户工作区保持干净
- **未来扩展**：AI 功能（智能归档 / 整理 / 优化）架构预留

## 技术栈

- 桌面框架：**Electron**（主进程 Node + 渲染进程 React）
- 语言：**JavaScript**；构建工具 **electron-vite**
- AI：当前版本不含；模型抽象层架构预留（PRD §7）
